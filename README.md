# PulseAI 🤖

A full stack AI chatbot with real-time web search, built with Flask, Python, Groq LLM and SerpAPI.

## Features
- 💬 AI-powered chat using Groq (LLaMA 3.1)
- 🔍 Real-time Google web search via SerpAPI
- 🔐 User authentication with hashed passwords
- 🗄️ MySQL database for chat history
- 📱 Clean responsive UI with sidebar

## Tech Stack
- **Backend:** Python, Flask
- **Database:** MySQL, SQLAlchemy
- **AI:** Groq API (LLaMA 3.1)
- **Search:** SerpAPI
- **Frontend:** HTML, CSS, JavaScript
